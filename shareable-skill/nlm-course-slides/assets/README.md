Place the shared local logo image here as `logo.png`.

The `nlm-course-slides` post-processing workflow will use this file by default on a new machine:

- Expected path: `assets/logo.png`
- Override option: pass `--postprocess-image-path <absolute-path>` to `monitor_and_finalize_slides.py`

If you share this skill with another user, send the logo image together with the skill and ask them to save it as `assets/logo.png`.
